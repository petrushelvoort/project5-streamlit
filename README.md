# Projeto: Análise de Veículos com Streamlit

Este projeto apresenta um aplicativo web desenvolvido com Streamlit para explorar um conjunto de dados de anúncios de veículos usados.

## Funcionalidades

- Leitura de dados a partir de um arquivo CSV
- Geração de histograma da coluna "odometer"
- Geração de gráfico de dispersão entre "odometer" e "price"
- Interface interativa com botões ou checkboxes
- Compatível com implantação no Render

## Como executar

1. Instale as dependências:
   pip install -r requirements.txt

2. Execute o aplicativo:
   streamlit run app.py
